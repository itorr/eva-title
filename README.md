

# 🐧 福音战士标题生成器 - Evangelion Title Card Generator
又一个福音战士标题生成器

## 在线地址
https://lab.magiconch.com/eva-title/

## 功能
- [x] 自定义文字
- [x] 黑底白字
- [x] 白底黑字
- [x] 黑底红字
- [x] 模糊
- [x] 噪点
- [x] 锐化
- [x] 模仿95版画面
- [x] 保留输入原文，提示当前字型缺失的字符及 Unicode 码位
- [x] 输出画面比例 `2022-09-03`

## 说明
预览和图片导出使用同一套标题字型。页面会列出缺字及码位，并在预览和保存的图片中为缺字留出空白。
